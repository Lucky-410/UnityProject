# 资源与内存

## 加载与释放

LoadingManager 使用 Addressables 初始化资源目录、准备依赖、预加载关卡资源并异步切换场景。场景采用 ReleaseSceneWhenSceneUnloaded，场景卸载时归还句柄。重新开始关卡时复用已有预加载句柄，返回菜单后释放预加载引用。

常驻界面由 Resources 加载，保持一份 Canvas 和字体、样式缓存。背包图标、角色头像和场景业务引用在解绑时清空。返回菜单后，在加载遮罩下调用 Resources.UnloadUnusedAssets，释放已不再被引用的资源。

关卡对象池随场景卸载。活动对象与空闲对象都保留在池的层级内，避免单独销毁池后遗留活动实例。

## 缓存容量

| 缓存 | 默认上限 | 超出时的处理 |
| --- | --- | --- |
| 敌人空闲实例 | 每种 8 个 | 归还时销毁多余实例 |
| 投射物空闲实例 | 16 个 | 归还时销毁多余实例 |
| 特效空闲实例 | 12 个 | 归还时销毁多余实例 |
| 活动特效 | 24 个 | 复用最早到期的特效 |
| 伤害文字 | 32 个 | 复用最早显示的文字 |

敌人与投射物不限制活动实例数量，避免高峰时遗漏战斗行为；限制的是高峰结束后的空闲缓存。特效和伤害文字只影响表现，可以限制并发数量。

## 分配与音频

特效回收、敌人死亡回收、受击闪烁和喝药动画使用计时器，减少重复创建协程与等待对象。拾取提示只在目标或数量变化时格式化文字，方向导航复用按钮列表。

菜单和关卡音乐使用 CompressedInMemory，在播放时解码，减少整段 PCM 常驻内存。短音效保持原配置。

未被场景和代码引用的参考图 chart.png 移至 Assets/Art/Reference，保留原 GUID，避免 Resources 将参考图打入游戏资源。

## 检查

玩法回归见 ArchitectureValidation/Result.txt，对象池、分配与场景切换检查见 MemoryValidation/Result.txt。编辑器总分配内存包含编辑器和资源导入开销，不能直接作为发布版本内存，也不能作为优化前后收益百分比。
