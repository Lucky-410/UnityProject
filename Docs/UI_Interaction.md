# UGUI 交互反馈

所有页面按钮、背包物品格、武器快捷栏和分类按钮统一使用 `Assets/Scripts/UI/UguiFeedbackButton.cs`。该组件继承 Unity 的 Button，通过 `DoStateTransition` 接收原生状态，点击、提交、禁用及 EventSystem 事件继续由 UGUI 处理。

| 状态 | 视觉反馈 |
| --- | --- |
| 普通 | 素材底图、正常文字 |
| 鼠标经过 | 亮边、背景光层、1.025 倍缩放 |
| 键盘焦点 | 青色边框与背景光层 |
| 业务选中 | 持续金色边框、金色角标；物品格、分类、装备栏同步实际选择 |
| 按下 | 0.96 倍缩放、压暗底图、橙色边框与文字 |
| 禁用 | 整体透明度降到 0.42，阻止点击及提交 |

鼠标经过不改变物品的选择；移开后，已选中格子恢复金色状态。效果在 0.10 秒内渐变，并使用真实时间，因此暂停界面也能播放。关闭页面会清理悬停和按下效果，恢复缩放。

`UguiTheme.cs` 创建不接收射线的状态光层、边框与角标，避免装饰遮挡按钮事件。`InventoryUguiView.cs` 通过 `SetChosen` 同步物品、武器栏和分类选择，不再通过反复改写 Button.colors 表现选中。

主菜单、操作说明和暂停/结算菜单支持 UGUI 的方向键导航与提交；进入页面先清空焦点，首次按方向键时才聚焦首个可用按钮，之后按方向键由 UGUI 移动焦点。离开时清理旧焦点。背包方向键保持原有的物品格选择，避免与 UGUI 空间导航同时移动。

按钮 Inspector 的“交互反馈”区域可以调整正常色、悬停色、选中色、渐变时长、悬停缩放和按下缩放。预制体 `Assets/Resources/UI/RelicfallUI.prefab` 已更新。
